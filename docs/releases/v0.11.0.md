# v0.11.0 — Arya Image Gen

AryaCode fork of dsh-image-gen, rebuilt around a local ComfyUI server.

## Breaking changes

- All cloud providers removed: Gemini, OpenAI, OpenAI-compatible relays, Seedream, DashScope, xAI Grok, and Zhipu GLM.
- Subscription sign-in channels removed: ChatGPT, Grok, Google.
- API-key settings, the test-connection route, and the credential UI removed. ComfyUI needs no key.
- The `generate_image`, `generate_images`, and `edit_image` tools now take a `workflow` argument instead of provider/aspect-ratio/size options.
- Studio emits one profile per imported workflow; the ratio, quality, and watermark pickers are gone.
- Comparison mode compares workflows instead of providers.
- Every user-facing string, document, and bundled inspiration entry is English.

## Added

- ComfyUI server controls in the settings card: Start, Stop, Restart, Refresh, live status with version/GPU/VRAM, configurable Python path, ComfyUI directory, extra `main.py` arguments, and optional auto-start.
- `POST /plugins/dsh-image-gen/comfyui-server` route (`status`, `start`, `stop`, `restart`).
- Studio, canvas, and batch generation through ComfyUI workflows, including edit-only workflows detected by their `{{image}}` input.
- Chat composer pill that switches the active workflow.

## Notes

- Upgrading from upstream settings keeps old fields inert; import workflows again because the provider is now ComfyUI.
- Stop never kills other processes on the ComfyUI port; it matches ComfyUI's own `main.py` command line.
