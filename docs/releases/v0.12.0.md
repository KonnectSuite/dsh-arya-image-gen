# v0.12.0 — Remote ComfyUI

## Added

- Remote ComfyUI servers: enter any reachable `http(s)` endpoint; generation, editing, and status use it without a local installation.
- `Request headers` setting (JSON object) applied to every ComfyUI request, for reverse-proxy tokens, Basic auth, or API gateways.
- Reverse-proxy subpaths: API paths resolve relative to the configured endpoint, so `https://example.com/comfy/` works.
- Actionable connection errors that name the URL and remote-server checklist (listen address, firewall, credentials, TLS).

## Changed

- For a non-local endpoint the settings card hides Start / Stop / Restart and the Python/ComfyUI path fields; it only probes status.
- Local launch fields default to empty instead of one developer's Comfy-Desktop path; Start explains what to set.
- Auto-start is skipped for remote endpoints.

## Upgrading

Existing local setups keep working. If Start now asks for paths, set the Python executable and the ComfyUI directory once.
