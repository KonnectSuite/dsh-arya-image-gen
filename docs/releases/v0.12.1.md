# v0.12.1 — prompt-context compatibility

Fixes a failure that made every agent turn fail on AryaCode 0.2 while the plugin was enabled:

```
This turn failed: unknown prompt variable "{{image}}" in context "dsh-image-gen:image-defaults"
```

AryaCode 0.2 interpolates `{{name}}` variables in system-prompt context text, and an unknown variable aborts the turn. The image-tools context described the workflow image placeholder with literal double braces. It now names the placeholder in words.

## Changed

- System-prompt context never contains literal double braces.
- Dynamic values interpolated into context (active workflow name, canvas text and prompts) are escaped, so user-drawn text such as `{{x}}` cannot break a turn.
- Added tests covering both contexts.
