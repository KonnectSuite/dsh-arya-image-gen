# v0.13.0 — mode-first Studio, hardened workflow states

The Studio no longer asks which workflow to run. The mode decides it.

## Changed

- **Text to image** runs the active/default workflow automatically; **Image to image** runs an edit-capable workflow automatically.
- The workflow picker moved into a collapsed **advanced** row; opening it overrides the choice for the session.
- Image to image is disabled when no edit-capable workflow is imported, with the reason on the button and in the panel.
- Generation is disabled, with an explicit message, when no workflows are imported at all.
- Silent refreshes reconcile by workflow name instead of provider/channel, so a removed workflow no longer leaves a stale selection.

## Server

- A Studio request with no imported workflows now fails with “No ComfyUI workflows are imported. Import an API-format workflow JSON…”, before any profile lookup.
