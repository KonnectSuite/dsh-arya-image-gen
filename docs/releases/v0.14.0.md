# v0.14.0 â€” generation insight: telemetry and live progress

ComfyUI generations now report what they did and how long it took, and the Studio panel shows live progress while a job runs.

## Added

- Result provenance in the tool output, image card, Studio item, and gallery record: workflow, pixel dimensions, seed, queue wait, execution time, total time, queue position, and ComfyUI version.
- Live job telemetry from ComfyUI's WebSocket: queue position, current node (read from the workflow's `class_type`), step `value/max`, elapsed time, and the latest latent preview frame when the server emits one.
- `GET /plugins/dsh-image-gen/progress/<jobId>` snapshot, SSE stream, preview image, and `POST .../cancel`.
- Studio progress panel with a step bar, node label, elapsed timer, optional preview thumbnail, and a Cancel button that removes the prompt from ComfyUI's queue (`/queue` delete plus `/interrupt` when the job is executing).

## Changed

- The Studio request carries a client-generated `jobId`; the ComfyUI submission uses it as `client_id` so progress events and the WebSocket match the job.
- Studio generations report the timings they measured; `output` lines now include size, seed, queue, run, and version.

## Limitations

- Progress is best-effort. A blocked WebSocket upgrade (common behind header-authenticated proxies) falls back to elapsed time only; generation is unaffected.
- Preview frames appear only when ComfyUI is configured to emit them; no thumbnail otherwise.
- Inline progress in the chat transcript is provided by the plugin's own tool card (see v0.15.0); the Studio panel remains the fallback surface.
