# v0.15.0 — live progress in the chat card

The chat tool card now shows generation progress while ComfyUI works, instead of a static row.

## Added

- While `generate_image` or `edit_image` runs, its keyed tool card renders the live job: phase, elapsed time, current node, step bar, active workflow, and a preview thumbnail when ComfyUI emits frames.
- The card becomes the normal image result when the tool settles; no extra row and no duplicated image.
- The host registers chat tool jobs under a deterministic id derived from the tool call id, so the card can follow its own generation even with several calls in one turn.

## How it works

The plugin already owns the chat card through the keyed `tool.call.toolview` slot. The running phase (`phase: 'start'` with `callId`) was previously ignored; it now polls `/plugins/dsh-image-gen/progress/<jobId>` and renders the same data as the Studio panel.

## Limitations

- A tool card replaced by progress is not an assistant message: side-channel chatter still cannot be injected mid-call.
- Previews require ComfyUI to emit latent preview frames; progress works without them.
- Hidden model reasoning is still not exposed; only telemetry and model-authored text.
