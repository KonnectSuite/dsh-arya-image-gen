# v0.16.0 — the Arya Image preset

A preset for image sessions that stops paying for tools it never calls.

## Added

- An agent preset, **Arya Image** (`arya-image`), registered by the bundle. It keeps the core DSH working set and this plugin's six tools, and masks the tools every other mounted bundle registers.
- The mask row (`dsh-arya-image-gen/agent-toolset`) applies `ctx.tools.restrict({ allow })` in the preset's own scope, so the other bundles' schemas are not sent on every request.
- `agentPreset` config field (default `true`) to stop registering the preset.

## How it works

The image tools come from this bundle's host row, so they are host-wide registrations; the preset whitelists them rather than re-mounting the plugin, which would double-register its routes and tools. `ask_user_question` and `present` are mounted as preset rows because the base bundle does not provide them.

The allow list is filtered against the live registry before `restrict()` is called, because that call refuses names the host does not register. Any failure leaves the session unmasked rather than without tools.

## Limitations

- Presets are not sandboxes: masked tools remain executable on the host.
- A preset edited in the Web editor replaces the whole row list; later plugin updates do not merge into the edited copy.
- The preset is chosen per session; existing sessions keep the one they recorded.
