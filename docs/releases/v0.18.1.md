# v0.18.1 — ready-made workflow pack

The plugin now ships the workflows it recommends, and a templated workflow runs
without being told a size.

## Added

- `docs/workflows/` with four API-format workflows and a zip:
  `qwen-image-create.json` (text to image, `{{width}}`/`{{height}}`),
  `qwen-image-cutout.json` (RGBA cutout), `qwen-image-edit.json` and
  `qwen-image-remove-bg.json` (both image to image). They import as-is.
- The pack ships inside the npm tarball (`docs/workflows/*`).

## Changed

- A workflow that declares `{{width}}`/`{{height}}` no longer fails when a call
  omits them: the size falls back to 1024×1024, so `generate_image` keeps working
  from a plain prompt. Sampling placeholders stay mandatory, because a guessed
  step count or cfg silently changes the picture.

## Why

The pack maps one-to-one onto the roles the previous release introduced: one
create workflow with adjustable size replaces the square/portrait/wide exports,
and one edit workflow drives `edit_image`. Before this, importing the templated
create workflow would have made every size-less call fail.
