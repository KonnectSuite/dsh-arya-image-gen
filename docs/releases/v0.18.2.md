# v0.18.2 — the plugin arrives configured

A fresh install can generate immediately, and the plugin can pre-flight its own
workflows.

## Added

- **Prefilled workflows.** The four shipped Qwen Image 2.1 workflows are the
  configuration default, so a new profile lists *create (adjustable size)*,
  *cutout*, *edit* and *remove background* without importing anything. They come
  from `docs/workflows/`, embedded at build time by
  `scripts/sync-default-workflows.mjs`; `tests/default-workflows.spec.ts` fails if
  the embedded copy ever drifts from the pack.
- **Check against ComfyUI.** A button in the Workflows card pre-flights every
  configured workflow against the running server's `object_info` and names the
  missing node classes or model files. This is the plugin-native equivalent of
  the Comfy MCP server's `validate_workflow`, and it works on *templated*
  workflows: it checks classes and loader file names, the two things that
  survive placeholder substitution.
- `GET /plugins/dsh-image-gen/check-workflows` exposes the same report.

## Verified

All four prefilled workflows report clean against ComfyUI 0.37.4 — classes and
models both — and 384 tests pass.

## Notes

- Existing installations keep their own list; the prefill only applies where
  nothing is configured yet.
- The check needs the server up. With ComfyUI down it returns an error rather
  than a verdict.
