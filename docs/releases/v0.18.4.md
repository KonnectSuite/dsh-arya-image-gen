# v0.18.4 — Arya Image shows up in the preset list

The preset was registering, but it sat last in the picker (order 6), below the
fold of a list that already held seven entries — so it looked missing.

## Changed

- **Preset order 2.5**, directly after Arya Standard, instead of 6 at the end.
- **Registration is logged**: `arya-image-preset: registered arya-image (Arya
  Image)` on success, the existing warning with the reason on failure. A missing
  preset is now diagnosable from the log instead of guessed at.

## Not changed — the composer pill

The pill is opt-in (`showProviderPill`, default off). If it is visible, it was
switched on: **Settings → Plugins → Arya Image Gen → Interface → "Show the
workflow switcher beside the chat input"**. It is a human convenience for pinning
a workflow; the agent selects by role, and `list_workflows` lets it choose on
purpose, so the pill is not required for anything the model does.
