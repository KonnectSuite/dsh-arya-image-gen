# v0.18.8 — generation status stays visible, with a live canvas

The "Generating image" panel and its progress bar used to live only inside the
tool card. When the host folds the call into its "calling tools" row and prints
the thinking status underneath, the panel disappeared at exactly the moment
someone wanted to watch it.

## Changed

- **A status dock above the composer.** The panel now renders in
  `conversation.input.dock`, a list slot outside the conversation stream, so it
  stays put while the run is thinking and the tool row is folded. It shows the
  phase, elapsed seconds, the step progress bar, the running node, the workflow,
  and a thumbnail.
- **A live canvas instead of an empty box.** The thumbnail is ComfyUI's latent
  preview when the sampler emits one; before the first frame — and on workflows
  that never emit previews — it is an animated shimmer with the `value/max` step
  badge, so the panel always reads as work in progress.
- **The inline card keeps its own progress**, now with the same shimmer fallback
  and the same "Preparing / Queued / Generating image" phases.
- **Fixed a stylesheet typo** (`.n.dsh-ig-progress` instead of
  `.dsh-ig-progress`) that left the inline panel without its layout, border or
  background.
- `src/client/generation-activity.ts`: a small framework-free store the card
  publishes into and the dock subscribes to, keyed by tool-call id and session,
  so two sessions never show each other's job.

## Verified on the dev profile

Ran two real generations on `dsh --profile dev` and checked the page while the
turn was still thinking:

- dock visible above the composer reading `Generating image 4.8s`, progress bar,
  `0/1` on the shimmer thumbnail, node `VAEDecode`, workflow
  `Qwen_Image_2_1_Turbo_Wide_1344x768.json`, while the stream showed
  "Deep diving for 9s";
- the dock disappears on its own once the image result arrives;
- both generations completed and were saved by the workspace rule.
