# v0.19.0 — the HTML and SVG render tools are gone

`render_html`, `render_svg` and `list_render_templates` are removed, together
with everything that existed to serve them: the render route, the Chromium
driver, the template pack, the Studio **Render** tab and the rendering settings
section.

## Why

A model that writes HTML and SVG itself does not need a second, weaker route to
a picture. The tools competed with that ability instead of complementing it:
rasterizing a page produces a PNG that looks like evidence while proving
nothing, and a request that is really a layout job turned into a detour through
a plugin feature nobody asked for. v0.18.13 spent a release teaching the tools
what they are *not* for; the honest fix was to take them out of the prompt
instead of asking the model to ignore them.

ComfyUI is what this plugin is for. Adding two rasterizer tools to the same
prompt made the plugin harder to steer, not more capable.

## Removed

- **Tools**: `render_html`, `render_svg`, `list_render_templates`. Eleven image
  tools became eight.
- **Routes**: `/plugins/dsh-image-gen/render` and
  `/plugins/dsh-image-gen/render-health`.
- **Modules**: `src/render-tools.ts`, `src/render-route.ts`,
  `src/render-service.ts`, and `src/render/` (browser discovery, sanitizer,
  templates, web-page guard, PNG encoder).
- **UI**: the Studio **Render** tab and its view, and the **HTML and SVG
  rendering** settings section with its renderer health line.
- **Settings**: `renderBrowserPath`, `renderDefaultWidth`, `renderDefaultHeight`,
  `renderScale`, `renderBackground`, `renderTimeoutMs`, `renderSaveSource`. An
  old profile that still carries them boots unchanged; the keys are simply
  ignored now.
- **Assets**: `assets/fonts/` (Sora and JetBrains Mono came with the package
  only so rendered text matched the brand) and `docs/assets/render/`.
- **Skills**: `html-to-png` and `svg-to-png`.
- **Docs**: `docs/rendering.md` and `docs/render-plan.md`.

## Changed

- `ImageProvider` is `comfyui` only; the `html` and `svg` provider ids and their
  display names, default models and base URLs are gone.
- The **Arya Image** preset persona and the `arya-image-workflows` and
  `arya-image-references` skills no longer route a layout request to a renderer:
  they say plainly that a diffusion model cannot guarantee lettering.
- The README hero banner is re-rendered: the three sources are now the shipped
  workflow roles (text to image, edit and restyle, cutout), the tool count reads
  eight, and the "your markup" band is gone. It is rasterized with headless
  Chrome from `banner-build/hero.html`, since the plugin no longer renders.
- The Studio tab strip is Gallery · Studio · Inspiration · Favorites.

## Tests

`tests/render.spec.ts` and `tests/web-page-guard.spec.ts` were deleted with the
code they covered; the tool-name and tool-registration assertions in
`tests/agent-preset.spec.ts` and `tests/index-unsupported-settings.spec.ts`
now expect the eight-tool set. 382 tests pass (383 with one live-ComfyUI test
skipped), 36 spec files, typecheck and build clean.

## Upgrade note

Nothing to migrate. Images made by the old tools are ordinary attachments and
stay in the gallery; only the tools that made them are gone.
