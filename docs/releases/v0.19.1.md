# v0.19.1 — full DSH tool set and billion-context stand-down

The Arya Image preset now mounts the full shipped DSH standard tool row set
(scheduling, delegation, goals, skills, plan mode and the rest) and stands its
compaction summary rows down when `billion-context` owns the context lane.

## Preset

- The preset row list matches the shipped DSH standard rows, minus the
  AryaCode `arya-review-skills` provider this plugin does not ship. The
  conditional plugin-manager row follows `profileContext`; the market row stays
  disabled.
- `billion-context` is detected only through its `biliBasicCompactionPolicy`
  gate service **and** its `__BILI_DSH_COMPACTION_VERDICT__ === 'active'`
  process verdict. When both are present, `compaction-basic` and
  `command-compact` mount disabled; the tool-result pruner and every other row
  stay mounted. Bili's kill switches, an absent bili, or a timeout keep the
  stock rows and change nothing.
- The definition-time check is deliberate: bili's `internal/config` overlay
  cannot reach a preset registered through `agentPresets.register()`.

Verified: `pnpm run typecheck`, `pnpm test` (421 passed, 1 skipped), `pnpm run
build`, and `pnpm run pack:check`. A live bili profile confirmed the helper
returns true with bili active and false with `BILLION_CONTEXT_PLUGIN=0`.
