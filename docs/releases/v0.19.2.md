# v0.19.2 — the preset pays only for the tools it uses

v0.19.1 made the Arya Image preset mount the full shipped DSH standard row list.
That put goals, skills and the `skill` tool, plan mode, scheduling, delegation, a
todo list and the plugin manager into an image session's tool definitions, where
none of them serve the work and every schema is paid for on every request. This
release cuts the preset back to the image tools and a small core set.

## Preset

- Rows are now: the persona, `agent-instructions`, `time-context`, both shell
  rows (one disabled), `tool-fs`, `tool-fs-search`, `tool-jobs`, the compaction
  group, `tool-ask-user`, `tool-web`, `present`, and the tool mask.
- The session's tool list is 23 tools: the eight image tools, `read`, `write`,
  `edit`, `glob`, `grep`, `read_image`, `working_directory`, `pwsh` (or `bash`),
  `job_list`, `job_output`, `job_kill`, `web_search`, `web_fetch`,
  `ask_user_question` and `present`.
- A last row, `dsh-arya-image-gen/agent-toolset`, masks every global tool the
  allow list does not name. Rows alone cannot do that: a tool registered by the
  preset's own rows lives in the agent scope and is exempt from a restriction,
  and the host registers other bundles, MCP servers and computer use globally.
- `working_directory` is not a row of this preset - the host mounts it globally -
  so the mask is what keeps it.
- `src/agent-preset/plan-section.ts` is gone with the plan-mode row. The
  definition builder no longer takes `profileContext`: no remaining row needs
  that service.
- The persona now says the session has no skills, subagents, goals, plan mode,
  scheduling or todo list, instead of claiming the full DSH tool set. The two
  shipped skills still load in other presets; this preset carries the condensed
  guidance in its persona.

## Fail-open

The mask drops names the host does not register (it reads them out of the
registry's own refusal) and leaves the session untouched if the restriction is
refused outright. A session that loses its tools is worse than one that pays for
a few extra schemas.

Verified: `pnpm run typecheck`, `pnpm test` (422 passed, 1 skipped), `pnpm run
build`, and `pnpm run pack:check`.
